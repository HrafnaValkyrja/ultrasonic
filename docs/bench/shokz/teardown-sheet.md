# Shokz teardown measurement sheet (packaging reference, O27)

Do this before any listening test. Photograph each step. Use calipers (mm) and a kitchen scale (g).

Safety: if the battery is swollen, dented or warm, stop. Do not puncture, charge or bend it. Put it in a non-flammable dish and recycle it. Never reuse it.

| # | Item | Measure | Value |
|---|---|---|---|
| 1 | Battery cell | length x width x thickness (mm), mass (g), label capacity (mAh) | |
| 2 | Main board | length x width (mm), thickness incl. tallest part (mm), mass (g) | |
| 3 | Transducer (each side) | diameter or L x W (mm), thickness (mm), mass (g) | |
| 4 | Transducer pad | contact face size (mm), material, how it is fixed | |
| 5 | Whole housing (each side) | L x W x H (mm), mass with and without cell (g) | |

Also note (one line each): connector type between board and transducer, any visible chip markings, how the shell is glued or clipped (for serviceability).
Use: compare against the pod envelope (thin first, then short, then long; O27).
