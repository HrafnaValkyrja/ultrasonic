# R-r6-nomass: louder playback with the CURRENT pad driver, zero added mass (rabbit trail, II round 6, 2026-10-08)

Hard rule: ear-side mass <= RC-BC02 pad (1.2 g `[Low]`) + 0.5 g; exciter swaps dead (R-light-driver.md, 9ed8b1a). No WebSearch run (budget); numbers are repo-derived or **[recalled]** (unverified, treat as order of magnitude). Baseline: bridge +-3.0 V, 208 mA FWSIM-R64 clamp, look-ahead limiter (I-001), RC-BC02 Bl ~1.0 N/A ASSUMED (E1 unmeasured). Gains are at the SAME peak current unless stated. All bench claims close on E1 (swept sine through the real pod, force + ear-canal mic).

## Stack and recommendation
Stacking is not additive in practice: 1 (square) and 3 (crest) fight over the same peak headroom (use whichever wins offline; square already has crest 0 dB). Plausible no-mass total **+3 to +6 dB**: 1 or 3 (+2) + 2 (frequency, 0 to +4) + 4/5 (+1 to +3). For reference, I-001 limiter already gave +4.5 dB, alert margin office -4.4 dB, so this may not close the street gap (-24 dB) alone; physics-wise it narrows it.
**Do first:** (3) offline corpus test (hours, no hardware), (1) as an A/B knob `drive_shape` in knobs.yaml. **Bench (E1 day):** 2, 4, 5, 6 on one session. Neither needs any ear mass.
Open: RC-BC02 Bl and f0 unknown (E1); tissue impedance guessed; no primary source retrieved this run for contact-force/stiffness effects, so rows 4-5 rest on [recalled] values.
