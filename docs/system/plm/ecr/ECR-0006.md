# Weighted printed dummy pair: 2 h wear test + joint flex test before the board order

Status: proposed
Raised: 2026-10-01 by claude
Items changed: REG-POD-BODY, REG-ARM, REG-PAD, PHYSICAL

## Change

Mitigates R20 (wearability) and R24 (joint fatigue). Fits O18: rapid prototyping, no board needed.
1. Print a test-build pair from the current CAD (hw/mech/out/r1/spine STLs: tub, lid, spine top, adapter, pad cup/cap,
   strut), mirrored for left/right. Real NiTi wire in the arm (BOM: Kellogg's 0.75 mm superelastic, not yet ordered),
   set screws, Sugru contact face.
2. Ballast each pod to the real mass. Claude computes the target per side before printing: CAD volumes x resin density
   (Siraya Blu) + cell (Renata datasheet mass) + board + parts, via sim/checks/balance.py (old estimate 7.75 g per side
   for the smaller pod; rev 1 is larger). Ballast with steel shot or lead tape at the cell's position.
3. Wear 2 h (T5) with the Ear (open) playing; talk, chew, turn the head; note pressure points, Ear (open) contact,
   pull on the glasses, hair snag, look in a mirror. Flex-cycle the arm joint ~1000x by hand with a dummy litz bundle
   in shrink tube through the heel channel and strut bore; inspect for chafing.
4. Feed results back into shell_r1.py / heel.py / pad.py before the board order.
Owner prints and wears; Claude prepares the print list, mass targets and a one-page wear-test sheet.
