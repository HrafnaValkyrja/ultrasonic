# frame.py still carries the pre-rev-1 pod constants

Status: proposed
Raised: 2026-10-01 by claude
Items changed: PHYSICAL, REG-POD-BODY, REG-ARM, REG-PAD

## Change

`hw/mech/frame.py` is the "shared interface" the heel and pad import, but it still holds the pre-rev-1 pod:
PCB 20 x 11.5 at y 11.1-11.9, CELL = LP401230 envelope, BUTTON = KXT321, LID_SCREWS, WIRE_PAD, MIC_PORT z -1.0.
`hw/mech/shell_r1.py` overrides all of these locally (PCB 34 x 13 at y 12.1-12.9, Renata cell, KMT022 at
pod x 52.6, no screws, mic at ZC). Anything that still reads the frame's pod constants gets the wrong pod.

Options: (A, recommended) move the rev-1 values into frame.py and have shell_r1.py import them, deleting the
obsolete ones; (B) split frame.py into arm/pad constants (still valid) and mark the pod section obsolete.
Found 2026-10-01 while modelling relations (R-PHYS-FRAME).
