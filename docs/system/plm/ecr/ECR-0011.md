# DEFECT: mic port hole 0.77 mm off the lid port (footprint origin != port)

Status: proposed
Raised: 2026-10-01 by claude
Items changed: SUB-AUDIO-IN, REG-BOARD, REG-POD-BODY

## Change

DEFECT (found by the methodology research, verified 2026-10-01): the SPH0641 footprint's port hole is 0.77 mm from
the footprint origin. With U2 at board (3.9, 6.5, rot 90, B) the hole lands at board (3.13, 6.5), i.e. pod x 33.73,
while the lid port (shell_r1.py MIC) is at pod x 34.5. Board hole D0.6 and lid hole D1.0 overlap by only ~0.03 mm.
Fix (A, recommended): place U2 so the PORT, not the origin, is at board (3.9, 6.5): U2 origin to (4.67, 6.5) after
checking the courtyard against R2/C13. (B) move MIC in shell_r1.py to x 33.73 instead (moves the lid hex window).
Prevention: an executable interface check (mic port hole vs lid port position) run with plm.py status: see the
methodology recommendations (docs/research/methodology.md, item 1).
