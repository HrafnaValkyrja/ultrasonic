# Bridge leg B to TIM1 CH3/CH3N (PA10/PB15), drop R11

Status: proposed
Raised: 2026-10-01 by claude
Items changed: SUB-PROCESSING, SUB-OUTPUT, SUB-DEBUG-TEST, REG-BOARD

## Change

Owner decision. Move bridge leg B from TIM1_CH2/CH2N (PA9/PB0) to TIM1_CH3/CH3N: GB_P on PA10 (pin 31),
GB_N on PB15 (pin 28), both AF1 (DS13737 Rev 10 Table 27, per the congestion agent; re-verify).
GB_N becomes a 2.3 mm hop; R5 (100k P-gate pull-up) then also holds PA10 high for the ROM bootloader, so R11 goes.
PB15's reset pull-down holds the N gate off (harmless). Firmware: the PWM DMA burst covers CCR1-CCR3 (DBL = 2).
Frees PA9 and PB0. Risks: PA10 is USART1_RX for the bootloader: confirm the bootloader never drives it.
