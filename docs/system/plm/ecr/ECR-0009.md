# Safety interlocks (no output while docked, output ceiling), charge logging, supervised first charge

Status: proposed
Raised: 2026-10-01 by claude
Items changed: SUB-POWER, SUB-OUTPUT, SUB-DOCK-USB, SUB-PROCESSING, SUB-DEBUG-TEST

## Change

Mitigates R23 (safety). Firmware + procedure, plus owner review:
1. Firmware interlocks: no exciter output while VBUS is present (docked = not worn, never charge while worn);
   output ceiling (D17) enforced in firmware, independent of the volume control; pop-free start.
2. Charging: JEITA via the BQ25180 TS/NTC; charge current set over I2C (~1C at 20-45 C, reduced below 20 C);
   charger faults and temperature logged over USB.
3. Thermal: board and cell temperature during a full charge measured on rev 1 (TS/NTC + a probe), before any wear.
4. Supervised first charge procedure (in a fire-safe spot, on the bench, with the cell's PCM verified).
5. The owner reviews every ECR touching SUB-POWER or the cell against the datasheets.

**Open conflict (found 2026-10-01 in the docs editor pass; owner decides).** Item 1's "no exciter output while VBUS
is present" also blocks the O15/O18 self-test, which runs over USB through the dock: the exciter |Z| sweep and the
PWM-noise A/B both need the bridge running (sub-output issue 12, sub-debug-test issue 12, sub-power issue 5).
- (a, recommended) Add a self-test exemption: output only in the USB self-test mode, drive capped (e.g. <= -12 dBFS,
  which also keeps the peak well under U4's 300 mA, ECR-0005, and limits U4 heating at the 4.5 V docked VSYS), never in
  normal docked operation.
- (b) No exemption: run the sweeps on battery, log to flash, read the results over USB afterwards.
