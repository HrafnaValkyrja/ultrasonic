# DEFECT: wrong LCSC numbers baked into imported footprints (Q1/Q2, SW1)

Status: implemented (awaiting owner review)
Raised: 2026-10-01 by claude
Items changed: REG-BOARD, COST

## Change

DEFECT (found by the methodology research, verified 2026-10-01): EasyEDA-imported footprints carry an "LCSC Part"
property from the part they were imported from, not ours: SOT1216_L1.1-W1.0-P0.35-BL-EP has C552750 (Q1/Q2 are
C19654206), SW-SMD_4P-L3.0-W2.6-P1.85-LS3.4 has C221708 (the 3.4 N KMT031; ours is the 1.6 N KMT022, C221707).
The JLC BOM comes from gen.py and is correct, but any board-based BOM/CPL tool would order the wrong parts.
Fix: strip "LCSC Part" from every footprint in hw/lib/lcsc/lcsc.pretty (part identity lives in the schematic only),
and add a bom_check that compares board footprint fields with the netlist (methodology item 3).
