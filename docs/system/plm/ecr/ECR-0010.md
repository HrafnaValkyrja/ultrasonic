## Change

Mitigates R22 (dead on arrival with no clue). Before the board order:
1. Written bring-up plan (sub-debug-test.md): power each block through the isolation links in order, what to measure

   emulator (Renode, MIT licence, if it supports the STM32U575; to be checked) for peripherals; a minimal "board
   alive" image (clocks, LED, USB CDC, self-test report) ready on day one.
3. Order 5 boards, 2-3 assembled, so one can be sacrificed for probing.
4. Results of the pre-mortem workflow (planned) add any hooks rev 1 still lacks.
