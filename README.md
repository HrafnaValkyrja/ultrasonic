# Stereo Ultrasound

A glasses-mounted wearable that shifts ultrasound (≈20–96 kHz) down into the audible range and plays it by bone conduction, in stereo, in real time.

- **Spec (source of truth):** [`docs/spec.md`](docs/spec.md). §1 is the owner-locked MVP.
- **Research findings:** [`docs/research/`](docs/research/), one file per task ID from spec §12.

Status: concept phase. Phase 1 (DSP simulation in Python) is next.
